# Python OOP Concepts 🐍

A collection of 4 OOP programs covering core Python concepts.

---

## 1. Magic Methods — Vector Class

**Concept:** Operator overloading using `__add__` and `__mul__`

**File:** `01_vector_class.py`

**Output:**
```
Vector(6, 4)
Vector(6, 9)
```

---

## 2. Class Variables — Employee Counter

**Concept:** Class-level variable that tracks total instances created

**File:** `02_employee_counter.py`

**Output:**
```
Harika
3
```

---

## 3. Encapsulation — Bank Account

**Concept:** Protected attributes, controlled access via methods

**File:** `03_bank_account.py`

**Output:**
```
1500
```

---

## 4. Multiple Inheritance — Duck Class

**Concept:** MRO (Method Resolution Order) with multiple parent classes

**File:** `04_duck_multiple_inheritance.py`

**Output:**
```
Flying!
(<class '__main__.Duck'>, <class '__main__.Flyer'>, <class '__main__.Swimmer'>, <class 'object'>)
```
